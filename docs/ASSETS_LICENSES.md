# Registro de Licencias y Recursos — HOME PROJECT (Hito 5)

## 1. Disponibilidad de Bibliotecas Externas
- **BlenderKit:** Addon activo en Blender `5.3.0 Beta`, sin `api_key` configurada (`api_key_set: False`).
- **Poly Haven / Sketchfab / Poly Pizza (MCP):** Desactivados en la configuración de usuario (`"off"` en `get_addon_status`).
- **Decisión de cumplimiento:** No se realizaron descargas no autenticadas ni compras. Todos los materiales PBR y el mobiliario mejorado de Hito 5 se construyeron mediante geometría propia (`bmesh`, modificadores `Bevel` y `Subsurf`) y nodos procedurales estándar de Blender (`Principled BSDF`), con licencia **100% propia / libre de regalías** y compatibilidad directa para horneado (*bake*) hacia Unity FBX.
